# Web Scraper Project

## Objective
Extract information from the ShadowFox website using BeautifulSoup.

## Technologies Used
- Python
- Requests
- BeautifulSoup

## Features
- Extract website title
- Extract headings
- Extract paragraph data
- Save extracted information to a text file
- Error handling for website connection issues
  
## Information Extracted

The scraper collected:

- Company title
- Program information
- Certification information
- Student success information
- Institution partnerships
- Career ecosystem details
  
## Output
The extracted information is stored in:
shadowfox_data.txt
